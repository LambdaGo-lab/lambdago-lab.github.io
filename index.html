Teapot LLM

LLM RAG

Teapot LLM is an open-source fine-tuned ~800M parameter language model optimized for hallucination-resistant question answering on CPU and mobile devices. Built for production environments where accuracy matters more than creativity, it delivers reliable extractive QA with minimal compute overhead.

LLM Multi-Agent Chat

Multi-Agent RAG MCP Orchestration Streaming

An open-source multi-agent chat system featuring LLM-based orchestration with intent routing, response evaluation, and safety moderation. Supports RAG-powered knowledge retrieval, MCP-based tool calling (finance, weather, web search), and real-time streaming via SSE. Compatible with Ollama, Gemini, Claude, and ChatGPT — configurable entirely through YAML.

NYC AI Traffic Camera Analysis

Object Detection Computer Vision GPU

Leveraging state-of-the-art object recognition models to analyze real-time traffic patterns from NYC's public traffic camera API. The system processes live camera feeds, detects and classifies vehicles, and generates actionable traffic flow analytics for urban planning and congestion monitoring.

Sports Analysis Tracker

Image Recognition Physics Simulation Video Processing

A Python library for automated annotation and tracking of physics objects in video footage. Supply a configuration file and video input, and the model outputs annotated footage with real-time object tracking and velocity estimation — enabling detailed sports performance analysis and motion studies.

Weave Language

Functional Programming Compilers

A custom programming language built in under a month for the REPL.it Coding Jam. Weave features type inference, functional evaluation semantics, and a C-like syntax — demonstrating end-to-end language design from lexer and parser to interpreter and runtime.
